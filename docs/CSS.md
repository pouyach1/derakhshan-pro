# CSS تم `tref` — راهنمای خواندن `allbd78.css`

فایل: `tref.digitaldesignnyc.co/wp-content/themes/tref/assets/css/allbd78.css`  
حدود ۱۸۴۹ خط، یک فایل واحد. خود فایل با کامنت‌های `/*** section ***/` بخش‌بندی شده؛ این سند همان بخش‌ها را به زبان ساده می‌گوید.

کد CSS تغییر نکرده است.

## واحد اندازه: `rem` این‌جا پیکسل نیست

```css
html { font-size: 0.052vw; }
```

یعنی `1rem` ≈ `0.052%` عرض ویوپورت. مقادیر مثل `128rem` یا `40rem` با عرض صفحه بزرگ و کوچک می‌شوند. برای اینکه از حدی ریزتر نشوند، تم زیاد از `max(px, rem)` استفاده می‌کند:

```css
--h1: max(40px, 128rem);
```

زیر `1023px` در media query، `html { font-size: 10px; }` می‌شود و خیلی از فاصله‌ها به پیکسل ثابت برمی‌گردند.

## توکن‌های `:root`

```css
--c1: #F2F1ED;   /* متن روشن / استخوانی */
--c2: #DCCBB3;   /* طلایی-کرم: دکمه، لینک، کلید، آیتم فعال */
--c3: #141414;   /* تقریباً سیاه */
--c4: #152621;   /* سبز خیلی تیره — پس‌زمینهٔ body */
--c5: #F3EAE1;   /* کرم روشن‌تر (کم‌استفاده در این فایل) */

--g1, --g2       /* گرادیان سبز تیره → سیاه، پایین صفحه */

--h1 --h2 --high --sub --btn --body --p1   /* اندازهٔ تیتر و فاصله */
--ease-out-expo: cubic-bezier(0.19, 1, 0.22, 1);
```

پس‌زمینهٔ صفحه `--c4` است. `body::before` یک گرادیان از پایین می‌گذارد. متن `--c1`، تاکید `--c2`.

## بریک‌پوینت‌ها

| عرض | چه عوض می‌شود |
| --- | --- |
| `1500px` / `1399px` | عرض ساب‌هدینگ بنر |

| **`1023px`** | لی‌اوت موبایل/تبلت: منوی همبرگر، ستون‌ها زیر هم، `font-size: 10px` روی html |

کلاس‌های نمایش متن تکراری:

- `.mob-hidden` — در دسکتاپ مخفی، از `1023px` به پایین `display: block`
- `.mob-hide` — برعکس: دسکتاپ دیده می‌شود، موبایل `display: none`

در HTML Home یک پاراگراف About دو بار آمده تا در دو عرض مختلف جای متفاوتی بنشیند.

## کامپوننت‌هایی که باید بشناسی

### دکمه `.button`

بوردر `--c2`، پس‌زمینه شفاف. هاور: متن `--c4`، پس‌زمینه `--c2`.

### لینک `.link-flash`

دو خط `::before` / `::after` زیر متن. هاور یکی scale می‌شود و دیگری محو؛ حس «چشمک خط».

### ورود متن `.reveal`

`.text-inner` از `translateY(100% + 20px)` شروع می‌کند. با `.reveal.animate` می‌آید روی جای خودش. همین الگو برای `.key` داخل reveal.

### تصاویر `.img-float img`

ارتفاع `120%` و `object-fit: cover` — جا برای حرکت عمودی (پارالکس) که JS روی wrapper اعمال می‌کند.

### خط تزئینی `.line-dash`

ارتفاع از `0%` به `100%` با transition 1.5s وقتی `.animate` بخورد.

## صفحات غایب در HTML، موجود در CSS

اگر بخواهی بفهمی About / Team / Contact روی سایت زنده چه شکلی‌اند، همین فایل کافی است:

**About**

- `.about-top` هیرو با کلید زیر تیتر
- `.about-team` گرید دو ستونه (در Home هم استفاده شده)
- `.history` تایم‌لاین چسبان (`.history-title { position: sticky }`) با سال‌های NanumMyeongjo رنگ `--c2`

**Investments**

- `.invest-top` دو ستون با خط وسط
- `.invest-form` همان فرم join
- `.invest-info` عکس + متن (در Home هم هست)
- `.slogan` جملهٔ بزرگ

**Team**

- `.box` دو ستون پرتره (`.box-img` ارتفاع زیاد)
- `.line-wrap` خط وسط

**Contact**

- `.contacts-info` آدرس/تلفن وسط‌چین رنگ `--c2`
- فرم
- `.contacts-keyhole` تصویر سوراخ کلید

**404**

- `.page-404-num` سه تصویر کنار هم (احتمالاً رقم‌های گرافیکی 4 0 4)

## چه چیزهایی عمداً در CSS نیست

رفتار این‌ها در `all.js` است نه در این فایل:

- اینیت Slick روی `.banner-slider`
- تایمینگ لودر
- Intersection / ScrollTrigger برای `.reveal` و `.line-dash`
- باز شدن `.header-nav` در موبایل
- splitlines روی slogan

CSS فقط **حالت‌های شروع و پایان** را تعریف کرده است.
