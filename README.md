# Derakhshan Pro

پروژهٔ React + Vite + Tailwind برای بخش **Done Deals**.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:5173/` را باز کن. صفحهٔ کامل گرید: `/done-deals`.

## ساختار

```
src/
├── assets/
├── components/
│   ├── layout/
│   └── ui/
├── pages/
├── App.jsx
└── main.jsx
```
